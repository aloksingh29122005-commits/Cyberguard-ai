What the checker looks for

  • Whether the link uses HTTPS
  • An IP number instead of a website name
  • Suspicious words such as login or verify
  • Too many subdomains, an @ sign, or lookalike letters
  • Very long links and link-shorteners
  • A famous company name on a website that is not theirs

This is a rule-based check, not AI. It can miss new tricks, and it can flag honest links that look unusual.
