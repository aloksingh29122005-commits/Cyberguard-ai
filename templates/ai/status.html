What is sent to the AI

  • Only your question or a short summary of a scan, never the whole email or message.
  • Passwords are never sent. The password check never uses the AI.
  • OTPs, PINs, card and phone numbers, emails and passwords written in a question are removed first.
  • Links keep their website and path, but lose logins and everything after a question mark.
  • The API key stays on the server. It is never in a web page or in JavaScript.

If the AI is off, slow or broken, you get a safe built-in answer and the app keeps working. AI answers can be wrong, so double-check anything important.

How to set it up

  1. Open the .env file in the project folder and copy the lines of one option from .env.example.
  2. Paste your own API key. Never share this file or upload it.
  3. Stop the app (Ctrl + C) and start it again, because settings are read when the app starts.
  4. Come back to this page and press Send a test question.
